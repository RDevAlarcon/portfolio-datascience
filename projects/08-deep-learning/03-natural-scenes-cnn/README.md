# Natural Scenes CNN

Notebook de clasificacion de escenarios naturales usando redes neuronales convolucionales.

## Archivo principal

- `natural_scenes_cnn.ipynb`

## Nota sobre datos

El dataset original usaba archivos `.npy` grandes para entrenamiento, test y prediccion. Esos archivos no se incluyen en el repositorio por peso. El notebook se conserva como evidencia del pipeline de CNN, arquitectura, entrenamiento y evaluacion.

## Habilidades mostradas

- Carga y preparacion de datos de imagenes
- Construccion de CNN con Keras/TensorFlow
- Capas convolucionales, pooling, flatten y dense
- Evaluacion de modelo de clasificacion de imagenes
