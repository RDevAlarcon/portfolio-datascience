# Hotel Booking Cancellation FFNN

Modelo de red neuronal feedforward para predecir cancelacion de reservas hoteleras.

## Archivos

- `hotel_booking_cancellation_neural_network.ipynb`
- `hotel_bookings.csv`

## Habilidades mostradas

- Limpieza y preparacion de datos tabulares
- Redes neuronales con regularizacion Dropout
- Busqueda de hiperparametros con Grid Search y SciKeras
- Evaluacion con accuracy, matriz de confusion, classification report y AUC
