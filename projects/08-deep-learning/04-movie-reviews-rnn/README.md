# Movie Reviews RNN

Notebook de analisis de sentimiento en criticas de peliculas usando procesamiento de texto y redes recurrentes.

## Archivo principal

- `movie_reviews_rnn.ipynb`

## Nota sobre datos

El material original incluia datasets de texto y embeddings grandes, incluyendo GoogleNews vectors. Esos archivos no se incluyen en el repositorio por peso. El notebook se conserva como evidencia de tokenizacion, secuencias, embeddings, entrenamiento y prediccion.

## Habilidades mostradas

- Procesamiento de texto
- Tokenizacion y padding de secuencias
- Embeddings
- Modelos recurrentes para clasificacion de sentimiento
